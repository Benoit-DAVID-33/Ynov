# TimeTravel Agency — Webapp Interactive

Webapp pour une agence de voyage temporel fictive, développée en solo.

## Auteur
- Benoît DAVID

## URL déployée
https://timetravel-agency-we-usx7.bolt.host/

## Stack technique
- React + Vite + Tailwind CSS
- Mistral AI API (mistral-small-latest)
- Déploiement : Bolt.host

## Features
- Landing page avec hero animé et CTA
- Galerie de 3 destinations temporelles avec visuels
- Modale de réservation par destination
- Chatbot IA conversationnel (Mistral AI)
- Design responsive dark mode

## IA utilisées

### Webapp (Projet 2)
- Génération de code : Bolt.new (Claude Sonnet)
- Chatbot : Mistral Small via API REST

### Assets visuels (Projet 1)
- Recherche & idéation : Gemini (LLM)
- Génération d'images : Gemini (Imagen 3) avec prompt engineering itératif
- Retouches & formats : Outpainting pour déclinaisons 16:9, 1:1, 9:16
- Animation vidéo (Img2Vid) : Luma Dream Machine / Hailuo AI
- Audio voix-off : ElevenLabs (ton luxe/narratif)
- Musique d'ambiance : Suno/Udio (orchestral cinématique)
- Montage : CapCut / Canva

## Méthodologie prompts
Template de prompt pour cohérence visuelle entre les époques :
- Image : "[EPOQUE], cinematic travel photography, luxury campaign style, golden hour lighting..."
- Vidéo : "Cinematic travel video, slow camera movement..."
